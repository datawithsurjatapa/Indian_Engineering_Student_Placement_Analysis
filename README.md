# Indian_Engineering_Student_Placement_Analysis
End-to-end data analytics project analyzing 15,000 engineering student records using Python, PostgreSQL, and Power BI. Includes data cleaning, exploratory data analysis (EDA), data visualization, and interactive dashboard development to uncover placement trends, academic and technical skill patterns, and salary insights.

---

## 📌 Project Overview

This project is an end-to-end data analytics project based on an Engineering Student Placement dataset. The main goal is to understand what factors are related to student placement and salary outcomes.

I worked on the project using **Python, PostgreSQL, SQL, and Power BI**. I started by cleaning and exploring the data in Python, then used PostgreSQL for SQL-based analysis, and finally created an interactive Power BI dashboard to present the findings.

---

## 📊 Dataset

The dataset contains **15,000 student records** and **27 attributes** covering academic performance, technical skills, activities, and placement outcomes.

## 🔄 Project Workflow

### 1. Data Loading

The dataset was loaded into Python using Pandas for initial inspection and analysis.

Key activities included:

- Understanding the dataset structure
- Checking rows and columns
- Inspecting data types
- Identifying missing values
- Checking duplicate records
- Understanding categorical and numerical variables

### 2. Data Cleaning & Preprocessing

The dataset was prepared for analysis by:

- Handling missing values
- Checking duplicate records
- Correcting data types
- Standardizing categorical data
- Creating useful analytical categories such as CGPA Level

### 3. Exploratory Data Analysis

EDA was performed in Python to identify patterns and relationships between student characteristics and placement outcomes.

Analysis included:

- Number of Students by Branch
- Placement Outcome & CGPA Distribution
- Salary Package Distribution
- Placement Rate by College Tier
- Average CGPA by Branch and Placement Status
- Correlation Analysis
- DSA Problems Solved vs Package Earned

### 4. PostgreSQL Analysis

The cleaned dataset was loaded into PostgreSQL for structured querying and deeper analysis.

The analysis focused on questions such as:

- What is the overall placement rate?
- Which college tier has the highest placement rate?
- Which groups have higher average salary packages?
- How does the placement rate vary across states?
- Is more studying always associated with better placement outcomes?
- How many students with strong technical profiles are still not placed?
- How does CGPA differ between placed and non-placed students?
- What is the placement rate across different genders?

## 📌 Key Insights

- Overall placement rate stands at **65%**.
- **Tier-1 colleges** have the highest placement rate at **96%**, compared with 72% for Tier-2 and 46% for Tier-3.
- **AIML, CSE, and IT** show the strongest overall placement and salary outcomes.
- Higher **CGPA, internship experience, and certifications** are associated with better placement outcomes.
- Placed students show higher averages in **DSA problems solved, study hours, GitHub contributions, and LinkedIn activity**.
- Placement and salary outcomes vary across **branches, college tiers, and states**.
